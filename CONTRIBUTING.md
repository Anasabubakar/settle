# Contributing to Settle

Thanks for helping make direct bill support safer, clearer, and more dignified.

1. Search issues and discuss material product/security changes first.
2. Keep one focused concern per pull request.
3. Never add wallet keys, provider tokens, real bills, personal data, or production destinations.
4. Run `npx tsc --noEmit`, `npm run lint`, and `npx expo export --platform web`.

## Product rules

- Support cannot be conditional on access, labor, publicity, repayment, romance, sexual content, religion, or politics.
- Never claim a payment settled without independent network confirmation.
- Treat uploaded documents as sensitive and redact/minimize by default.
- Keep mainnet payment construction, fiat conversion, provider verification, and secrets on the server side.

Use concise imperative commits, such as `docs: clarify testnet settlement boundary`.
